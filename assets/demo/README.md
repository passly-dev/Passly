# デモモード用の素材

`avatars/` は、デモモード（`--dart-define=DEMO_MODE=true`）で架空の人物に使うプロフィール画像です。
ファイル名は `lib/demo/demo_people.dart` の人物 ID です（`demo_me` は自分）。

## 風景（demo_03 / 04 / 06 / 09 / 11 / 13 / 15 / 17）

Python（Pillow）で描いて作ったオリジナルの画像です。外部の素材は使っていません。

## 動物（上記以外）

[Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji) の 3D 画像を、淡い背景色の上に載せたものです。
