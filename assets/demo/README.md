# デモモード用の素材

`avatars/` は、デモモード（`--dart-define=DEMO_MODE=true`）で架空の人物に使うプロフィール画像です。

- [DiceBear](https://www.dicebear.com/) の「Lorelei」スタイルで作成しました
- Lorelei は Lisa Wischofsky によるデザインで、ライセンスは [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) です（https://www.dicebear.com/licenses/）
- ファイル名は `lib/demo/demo_people.dart` の人物 ID です（`demo_me` は自分）
