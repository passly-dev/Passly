# タグのロゴ

タグのステッカーに使うロゴ．各技術でいちばんよく使われている公式の色つきロゴを使う．

- 多くは [Devicon](https://github.com/devicons/devicon)（MIT License）の色つきロゴ（original．ない場合は plain）．
- Go・Hono・Gin・Render・LangChain・Discord・shadcn/ui は [Simple Icons](https://github.com/simple-icons/simple-icons)（CC0 1.0）．色は各ブランドの色にしている（Go は公式の「GO」ロゴにするため Simple Icons）．
- SwiftUI は Swift のロゴを使う．
- ロゴは各社の商標．各社のブランドガイドラインに沿って使う．
